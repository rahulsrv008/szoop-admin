How the colours work
Tracking
Starts when the job is broadcast to agents: right after payment for "Right now" jobs and plans, and {{ board()?.dispatchLeadMinutes }} min before the start for scheduled jobs (on the next dispatch run). A job isn't shown before that. Zone admins only see jobs and agents in their zones.
Waiting for an agent
Timer starts at the broadcast (and again whenever an agent gives the job back). Orange after {{ r.waitingOrangeMinutes }} min, red after {{ r.waitingRedMinutes }} min. Orange straight away when no agent is online in its zone or dispatch found nobody free; red if it was due to go out and didn't, or its start time has passed.
Agent hasn't set off
Timer starts when the agent picks the job. Orange after {{ r.setOffOrangeMinutes }} min, red after {{ r.setOffRedMinutes }} min. Orange straight away if the agent isn't online. Plan visits aren't broadcast one by one, so their timer starts {{ r.setOffLeadMinutes }} min before each visit.
Agent on the way
Timer starts at the start time ("Right now": {{ r.instantArrivalMinutes }} min after setting off). Orange after {{ r.arrivalOrangeMinutes }} min, red after {{ r.arrivalRedMinutes }} min.
Work in progress
Timer starts when the booked time ends. Orange after {{ r.overrunOrangeMinutes }} min, red after {{ r.overrunRedMinutes }} min.
Agents
Orange when they have a job today and aren't online in the agent app; red once they should be heading to it.
